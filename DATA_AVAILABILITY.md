# Data availability

## Sequencing data (GEO)

Raw and processed single-nucleus multiome data for the four conditions are in GEO: **[GSE352076](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE352076)**.

| GEO sample | Accession (GEX / ATAC) | Library | Raw files (FASTQ) | Processed files |
|---|---|---|---|---|
| MCF7_Control_GEX / _ATAC | GSM10148529 / GSM10148530 | ct74 | SC60_1G (I1, I2, R1, R2) / SC60_1A (I1, R1, R2, R3) | `ct74_filtered_feature_bc_matrix.h5`, `ct74_per_barcode_metrics.csv` / `ct74_atac_fragments.tsv.gz` (+ `.tbi`) |
| MCF7_Acute_GEX / _ATAC | GSM10148531 / GSM10148532 | ct65 | SC60_2G / SC60_2A | `ct65_*` |
| MCF7_Chronic_GEX / _ATAC | GSM10148533 / GSM10148534 | aa65 | SC60_4G / SC60_4A | `aa65_*` |
| MCF7_Return_GEX / _ATAC | GSM10148535 / GSM10148536 | aa74 | SC60_3G / SC60_3A | `aa74_*` |

The processed files are Cell Ranger ARC 2.0.2 outputs, renamed with the sample prefix. To use them instead of rerunning [00-1_cellranger_arc](00-1_cellranger_arc), place them as `<DATASET_DIR>/<sample>/filtered_feature_bc_matrix.h5` and `<DATASET_DIR>/<sample>/atac_fragments.tsv.gz` (+ `.tbi`), and start from [00-2_seurat_preprocessing](00-2_seurat_preprocessing).

The series supplementary file `MCF7_snMultiome_cell_metadata.csv.gz` lists the 41,355 nuclei kept after QC. For each nucleus it gives the sample, condition, QC metrics and cluster labels (`acdc_sct`, `acdc_peaks`).

## Processed analysis objects (Zenodo)

Processed objects and result tables are on Zenodo: **[10.5281/zenodo.23550814](https://doi.org/10.5281/zenodo.23550814)**. File names start with the step that produced them, so each file can be placed in the matching `RESULTS_DIR` folder to start the pipeline from that step.

| Prefix | Files |
|---|---|
| `00-2_` | Integrated Seurat/Signac object after QC, MACS3 peaks, SCT/LSI/WNN, clustering and chromVAR (`all_qc_noMT_macs3_trf_chrvar.rds`, 41,355 nuclei) |
| `01_` | hdWGCNA metacell object, metacell count and CPM matrices, metacell metadata |
| `02_` | ARACNe3 consolidated network from the rerun, the original network used for the manuscript, regulator list |
| `03_` | VIPER regulon, VIPER activity, metacell object with VIPER and chromVAR |
| `04_` | Metacell object with axis pressure scores and dominant axis, diversity tables, thresholds |
| `05_` | msVIPER results and candidate regulator tables; per-contrast tables in `05_msviper_per_contrast_tables.tar.gz` |
| `06_` | chromVAR deviations of the candidate regulators (Extended Data) |

All files except `02_original_consolidated-net_mcf7_metacell.tsv.gz` were generated by this repository's code from the GEO files above. `.tsv`/`.csv` files are gzip-compressed. MD5 checksums are in `md5sums.txt`.
